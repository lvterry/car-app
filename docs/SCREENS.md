# 养车本 · 信息架构与三屏草稿（MVP）

配合 `PRODUCT.md` v0.3。

## 信息架构

```
养车本
├── 首页（时间线 + 下一件待办）
├── 记一笔
│   ├── 拍照 / 相册 → OCR 确认
│   └── 手填
├── 记录详情（编辑 / 删 / 看票据图）
├── 车辆（一辆：资料、当前里程、动力类型）
├── 导出履历 PDF
└── 导出备份 / 从备份恢复
```

底部不多 Tab。**首页为主**；主按钮「记一笔」；车辆与导出收在顶部「…」。

---

## 屏 1 · 首页

**任务：** 打开就知道下一件该做什么，并能记一笔。

1. 顶栏：车名 · 当前里程（可点改）·「…」（车辆 / 导出履历 / 导出备份 / Pro）  
2. **下一件待办**（唯一强调块）：项目 · 剩余里程或天数 · 状态（正常/临近/过期）·「已完成」→ 记一笔预填  
3. **最近记录**时间线：日期 · 项目 · 费用 · 里程  
4. 主按钮：记一笔  

空状态：「记下最近一次保养，之后我会提醒你」+ 主按钮。  
不做：健康分环、多图仪表盘、广告、小贴士墙。

---

## 屏 2 · 记一笔（含 OCR）

**路径 A（主）：** 相机/相册 → **确认页**（日期、里程、项目、费用、店名、备注；原图可看；全部可改）→ 保存并设下次提醒。  

**下次提醒：** 间隔默认可改；里程 / 时间 / 先到；可跳过。  

**路径 B：** 同一表单手填；可切「拍照录入」。  

**失败：**「没读出来，直接填也行」；保留照片。  

OCR 是加速器，确认是闸门。

---

## 屏 3 · 导出

**履历 PDF**  
范围：全部 / 按日期 → 预览 → 生成 → 系统分享。  
内容：标题与车信息 · 日期|里程|项目|费用|备注 · 合计 · 页脚免责（非官方认证）。  
Pro：去水印、稍好排版。未购可预览带水印 PDF。

**备份包**（同「…」另一入口）  
导出 JSON/ZIP（含收据图）；可简易恢复。与 PDF 分开，不绑 Pro。

## 文案备忘

| 状态 | 方向 |
|---|---|

| 过期 | 「机油保养已过期 · 建议尽快安排」 |
| OCR 中 | 「正在读票据…」 |
| OCR 失败 | 「没读出来，直接填也行」 |
| 里程软提醒 | 「该更新一下当前里程了吗？」 |
| OCR 定位 | 「识别成草稿，你确认后才保存」 |

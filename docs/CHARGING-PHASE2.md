# 充电账本 · 二期一页纸

## 一句话

帮电车/混动车主算清：花了多少电费、每公里多少钱、家桩和公共桩差在哪。仍是账本，不是找桩、支付或控桩。

## 何时开工

同时满足再开：

1. MVP 履历已有人真实在用（录入 + 提醒）  
2. 访谈/内测里「充电费算不清」进前两名痛点  
3. 不与履历主路径抢同一迭代  

## 做 / 不做

**做：** 记充电（日期、kWh、费用、家桩/公共、可选场站、里程）· 元/kWh · 可选 元/km · 月/年汇总与家桩 vs 公共占比 · 进同一时间线。  

**不做：** 实时电价爬取、桩企账号、扫码充电、导航找桩、电池健康、车厂 API（不作前提）。  

## 与 MVP 预留

- `Record.type` 含 `charging`（UI 可暂藏）  
- `Vehicle.powertrain`  
- 可选空字段：`kWh`, `locationKind(home|public)`  

二期应是「打开开关 + 一页汇总」，不是翻修首页。

## 商业化

基础记充电可免费；汇总对比可作为 Pro 卖点。

## 成功标准

连续 2 周至少 4 笔充电记录；能回答本月充电花费与大概每公里电费；不接车厂 API 仍觉得有用。
